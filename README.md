# NexusAI — SaaS Landing Page & Real-Time Analytics Dashboard

A responsive SaaS startup landing page and interactive executive dashboard built with **HTML5**, **Tailwind CSS**, **JavaScript**, and **Chart.js**.

## Key Features
- **Interactive Executive Dashboard:** Real-time KPI cards and dynamic Chart.js telemetry switching between 7-day, 30-day, and 90-day views.
- **Dynamic Pricing Engine:** Instant toggle between Monthly and Annual billing tiers with automatic 20% discount calculations.
- **Client Onboarding Modal:** Responsive lead capture and project booking modal with form validation.
- **Modern Dark-Mode UI:** Built with Tailwind CSS glassmorphism components and mobile-first responsiveness.
